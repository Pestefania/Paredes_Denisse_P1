
# Ficha del proyecto: Car Service

## 1. Datos generales

- **Nombre del proyecto:** Car Service
- **Tipo de sitio web:** Página web para un taller mecánico
- **Estudiante:** Denisse Paredes
- **Asignatura:** Programación y Plataformas Web
- **Tecnologías utilizadas:** HTML5 y CSS3
- **Enlace del sitio web:** https://github.com/Pestefania/Paredes_Denisse_P1


## 2. Descripción del proyecto

Car Service es una página web desarrollada para un taller mecánico, con el propósito de presentar los servicios que ofrece, mostrar sus precios y proporcionar información para que los clientes puedan solicitar una cita. El contenido está organizado en diferentes secciones para que los visitantes puedan encontrar la información de manera sencilla.

Para realizar el proyecto utilicé HTML5 para estructurar el contenido y CSS3 para definir los colores, los bordes, los espacios y la distribución de los elementos. La página cuenta con un diseño en tonos azules y fondos claros, buscando que tenga una apariencia ordenada y fácil de utilizar.

## 3. Características implementadas

### 3.1. Estructura semántica

Se utilizaron etiquetas como `header`, `nav`, `main`, `section`, `article`, `aside` y `footer` para organizar las diferentes partes de la página. También se incluyeron títulos y subtítulos para identificar el contenido de cada sección.

El menú de navegación permite acceder a las diferentes partes del sitio, mientras que la sección principal presenta información sobre el taller mecánico.

### 3.2. Diseño y presentación visual

Se utilizó una combinación de colores azules, blancos y celestes para mantener una apariencia uniforme. También se aplicaron estilos a los títulos, las tarjetas de servicios, la tabla de precios, el formulario y las preguntas frecuentes.

Para organizar los elementos se utilizaron Flexbox y CSS Grid. Además, se agregaron bordes, espacios y fondos claros para distinguir las secciones y facilitar la lectura del contenido.

### 3.3. Diseño adaptable

Se incorporó una media query para pantallas de hasta 640 píxeles de ancho. Mediante esta regla se ajusta la distribución del encabezado, el menú de navegación y las tarjetas de servicios.

Con estos cambios se busca que la página pueda visualizarse correctamente en teléfonos móviles y otros dispositivos con pantallas pequeñas. También se debe comprobar que no aparezca un desplazamiento horizontal innecesario al utilizar una resolución de 360 píxeles.

### 3.4. Formulario y validaciones

La página incluye un formulario para solicitar citas en el taller. Entre sus campos se encuentran el nombre, el correo electrónico, el teléfono, el servicio requerido, la fecha y una descripción del problema del vehículo.

Para organizar los campos se utilizaron etiquetas como `label`, `fieldset` y `legend`. También se incorporaron atributos como `required`, `type="email"` y `pattern` para establecer validaciones básicas en el navegador.

Estas características permiten comprobar ciertos datos antes de enviar el formulario y ayudan a identificar campos obligatorios o información que no cumple con el formato establecido.

### 3.5. Preguntas frecuentes y accesibilidad

Se implementó una sección de preguntas frecuentes utilizando las etiquetas `details` y `summary`, que permiten mostrar u ocultar las respuestas sin necesidad de utilizar JavaScript.

También se consideraron aspectos básicos de accesibilidad, como el uso de textos alternativos en las imágenes, etiquetas descriptivas en los campos del formulario y estilos de foco visible para facilitar la navegación mediante el teclado.

En la tabla de precios se utilizaron encabezados para organizar la información de los servicios y sus valores.

## 4. Aspectos que se revisarán

Para comprobar el funcionamiento y la calidad de la página, se revisarán los siguientes puntos:

- La estructura y la validez del código HTML5.
- La presencia de errores en la hoja de estilos CSS3.
- La navegación entre las diferentes secciones.
- La adaptación del contenido a pantallas pequeñas.
- La navegación mediante teclado y la visibilidad del foco.
- El funcionamiento de las validaciones del formulario.
- La apertura y el cierre de las preguntas frecuentes.
- La correcta visualización de las imágenes y la tabla de precios.

Para realizar estas comprobaciones se utilizarán las siguientes herramientas:

- [Validador HTML del W3C](https://validator.w3.org/)
- [Validador CSS del W3C](https://jigsaw.w3.org/css-validator/)

## 5. Estado del proyecto

La página web Car Service cuenta con una estructura desarrollada en HTML5 y estilos aplicados mediante CSS3. Se han incorporado secciones informativas, una tabla de precios, un formulario para solicitar citas y preguntas frecuentes.

Como parte de la práctica, se revisará el código mediante los validadores correspondientes y se realizarán pruebas de navegación, formulario y diseño adaptable. Esto permitirá identificar posibles errores y realizar los ajustes necesarios antes de la entrega final.
